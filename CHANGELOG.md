# Changelog

## 0.1.0

First public release.

- Fast scanning with a native directory reader, and an NTFS Master File Table turbo mode for administrators.
- Storage widget with a dot-matrix category bar, live scan progress and cleanup suggestions.
- Explorer with a size-sorted folder tree and a treemap, plus largest files, file types and search.
- Forgotten files: filter by last use, size and category, with smart folder grouping.
- Safe cleanup: Recycle Bin by default, protected system and key folders, confirmation with sizes, in-use files skipped.
- English, Russian, Chinese and Spanish; dark and light themes with an animated switch, both following the system by default.
- Low resource use: no GPU process, idle animations stop, the file index is released on the start screen.
- Windows installer and portable build.
